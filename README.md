# FIAP Delivery

Projeto desenvolvido para a CP2 da FIAP utilizando Java e conceitos de Orientacao a Objetos (POO).

## Descricao

O sistema gerencia entregas de pacotes utilizando rotas, veiculos (caminhao e moto) e regras de validacao de peso maximo.

## Estrutura

- Veiculo (Classe abstrata)
- Caminhao (Herda de Veiculo)
- Moto (Herda de Veiculo)
- Pacote
- Rota
- Principal (Classe com o metodo main e testes)
